# Contact Local

Development/test-only M6 adapters: append-only SQLite record storage, a read-only M5 catalog,
synthetic person/contact/sender verification, fixture jurisdiction policy, deterministic mock email,
signed fixture events, rule reply classification, and bounded first-party statement extraction.

This package performs no DNS, network, provider, webhook, enrichment, verification, or real delivery
operation. Only reserved fixture.invalid identities are accepted.

Forbidden responsibilities include provider SDKs/credentials, real recipients or senders, bulk
operations, retries after ambiguous submission, autonomous follow-up, live AI, or M7 behavior.
