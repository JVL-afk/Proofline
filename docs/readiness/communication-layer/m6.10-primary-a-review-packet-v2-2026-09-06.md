## 1. Durable suppression (finding 1)

- **Authority:** the existing `opintel_suppression` persistent registry
  (append-only sqlite / postgres, WAL). No new suppression code — only wiring:
  `opintel_suppression_local.build_durable_suppression_service` +
  `aplus_pilot_database_url()` + fixed `APLUS_PILOT_WORKSPACE_ID`.
- **Why the v1 check was in-memory:** the v1 package script hard-coded
  `SqlAlchemySuppressionRepository("sqlite:///:memory:")` *and* a per-run
  `workspace_id = uuid4()` — so every run queried a fresh empty namespace. Both
  are fixed: durable file URL + one stable pilot workspace id.
- **No in-memory fallback:** `require_persistent_database_url()` raises
  `InMemorySuppressionForRealSendError` for `sqlite:///:memory:` (or any
  non-persistent URL); the package builder calls it unconditionally.
