## The blocker

Every one of the 27 calls returned **thinking-only content**:

```
stop_reason : max_tokens
content     : [ {"type":"thinking", …} ]   # zero text blocks
usage       : output_tokens 2000, all thinking_tokens
```

`claude-sonnet-5` runs extended thinking by default. At the owner-authorized hard
ceiling `max_output_tokens = 2000`, the model consumes the entire budget on
internal reasoning and emits **no text block**, so the fail-closed adapter records
`GENERATION_REFUSED` ("anthropic returned no text content") for all 27 attempts.
0 candidates returned, 0 to validate, pass-rate 0.00 < 0.80 → `NOT_CERTIFIED`.

The API and credential are healthy — a control call with a small prompt and no
system message returned normal text (`model: claude-sonnet-5`, `stop_reason:
end_turn`). The plain-prompt token estimate the plan used (~3,550/call) was wrong
for a thinking model: observed input was ~5,900/call and output pinned at the
2,000 ceiling as thinking.

## Why this stopped here rather than being fixed in place

A working certification needs the model to emit draftable text within 2,000
tokens. The only ways to get that are generation-config changes, each of which
alters `generation_config_hash` — a member of the certification key
(authorization §8: "any change to any member invalidates the certification") —
and §14 requires owner review before a fix that changes the generation config,
the provider/model, or the hard ceilings. So this is an owner decision:

1. **Disable extended thinking** for the certification call
   (`thinking: {type: "disabled"}` in the request body). Cleanest: deterministic,
   keeps `max_tokens = 2000`, model returns text directly. Adds one explicit
   generation parameter (counter to the §2 "set nothing" minimalism, but thinking
   is not a sampling parameter). New certification key.
2. **Raise `max_output_tokens`** so a thinking budget plus a full JSON candidate
   set both fit (needs ~6–10k). Directly contradicts the §7 hard ceiling of 2,000
   — owner would have to lift that ceiling.
3. **Keep thinking, add a small text budget** — not separately controllable on the
   Messages API; `max_tokens` covers both. Same as (2) in practice.
4. **Accept `NOT_CERTIFIED`** as the final M6.8-3 result and revisit the whole
   approach.

Recommendation: **option 1**. Re-run is another ~27 paid calls (~USD 0.90) under a
new certification key, with a one-line note in the execution plan and this
document. No other machinery changes.
