# Milestone M5 — Evidence-Bound Outreach Package Engine

**Status:** Complete — deterministic local slice; production gates remain open
**Authorized:** 2026-08-18
**Completed:** 2026-08-18

## Objective

Produce an immutable, deterministic, human-reviewable Commercial HVAC outreach package from an
exact accepted M2 opportunity, approved M3 audit, and approved M4 demo. M5 creates no business
truth and performs no external action.

## Authority and exclusions

`M1 evidence -> M2 accepted opportunity -> M3 approved audit -> M4 approved demo -> M5 claim
projections and drafts -> hard QC -> human content review`.

`CONTENT_APPROVED` is wording approval only. Contact, legal permission, copy, export, download,
publication, public sharing, recipients, delivery, sending, scheduling, CRM/email/calendar/phone/SMS,
live AI, autonomous behavior, and M6 are excluded. A-16, A-17, and A-20 remain unresolved.

## Exit criteria

- [x] Exact current M2-M4 eligibility and entity lineage fail closed.
- [x] Immutable manifests bind every material upstream and configuration version.
- [x] External facts bind exact approved M3 claims and evidence.
- [x] Inferences, scoped absence, recommendations, and unknowns retain semantics.
- [x] Economics remain exact and internal-only; external artifacts contain no financial value.
- [x] The approved template, role taxonomy, CTA, disclosure, and follow-up precondition are enforced.
- [x] Internal risks, contradictions, alternatives, gaps, and assumptions cannot leak as certainty.
- [x] Hard QC is non-overridable and deterministic replay hashes match.
- [x] Human content review is exact, attributed, and invalidated by upstream drift.
- [x] API/UI expose inspection and review only; no copy/export/send/public capability exists.
- [x] Hostile, authorization, idempotency, immutability, and zero-network tests pass.
- [x] Complete M0-M5 deterministic validation passes without live AI or external side effects.
- [x] No M6 behavior is present.

## Implemented local slice

M5 adds typed domain/application/port boundaries, append-oriented SQLite operations and revisions,
a read-only canonical M1-M4 catalog, exact hashed manifests, typed claim projections, deterministic
plain-text artifacts, structural audience separation, internal-only economics, functional-role
targeting with `NO_PERSON_IDENTIFIED`, material-risk visibility, hard QC, bounded idempotent workflow
execution, exact content review, and upstream invalidation. The authenticated diagnostic UI exposes
inspection and content review only. The provider-neutral wording port has no adapter or route.
