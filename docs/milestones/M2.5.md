# Milestone M2.5 — AI Qualification Infrastructure

**Status:** Complete — provider-neutral, offline qualification infrastructure validated
**Authorized:** 2026-08-17
**Completed:** 2026-08-17

## Purpose

Provide a provider-neutral, fixture-based way to decide whether an exact model deployment qualifies
for an intelligence task. Deterministic M2 remains authoritative. Evaluation artifacts are separate
and cannot mutate evidence, opportunities, assumptions, economics, scores, or human review.

## Scope

- Four M2 reasoning task contracts.
- Immutable deployment registry and version-specific qualification lifecycle.
- Controlled versioned corpus partitions and hostile fixtures.
- Atomic metrics and non-aggregatable hard safety gates.
- Deterministic mock providers and network-free CI.
- Evaluation-only, shadow, and advisory routing with deterministic fallback.
- Invocation/cost ledger and deterministic budget adapters.
- Disabled live-evaluation policy interfaces.

Future audit composition, visual analysis, and low-latency conversation are taxonomy-only. Live AI,
autonomous agents, authoritative model decisions, and M3 behavior are excluded.

## Exit criteria

- [x] ADR-0011 through ADR-0014 are accepted while A-10 remains unresolved.
- [x] Evaluation records are structurally separate from canonical M2 records.
- [x] Exact task, deployment, schema, policy, corpus, configuration, and data-class keys govern qualification.
- [x] All required fixture families and hostile variants are present.
- [x] Every critical fabrication path fails a hard gate and cannot be masked by aggregate metrics.
- [x] Mock deployments prove valid, malformed, hostile, inconsistent, timeout, transient, and budget behavior.
- [x] Only actively qualified deployments route; failure returns deterministic M2 fallback.
- [x] Drift suspends qualification and requires re-evaluation.
- [x] Invocation provenance, usage, latency, retry, fallback, pricing, cost, and validation data persist.
- [x] Live evaluation remains disabled, allowlisted, budgeted, and absent from normal CI.
- [x] Workspace authorization and M2 isolation tests pass.
- [x] Complete M0–M2.5 validation passes with no M3 behavior.

## Completion verification

The implementation adds only `qualification-core` and `qualification-local` packages plus
deterministic tests and governance documentation. The qualification packages do not import the M2
opportunity context and their SQLite adapter owns only `qualification_*` tables. The controlled
corpus covers all five partition concepts and all approved product/hostile families. Twenty M2.5
tests prove hard gates, retries, lifecycle/drift, qualified-only routing, deterministic fallback,
budgets, safe ledgers, live-boundary denial, workspace isolation, zero network access, and canonical
M2 immutability. The complete M0–M2.5 suite contains 52 passing tests.
