## Execution stages

1. Secure credentials and validate the deterministic baseline.
2. Certify each adapter with one bounded contract round trip.
3. Run the critical safety gauntlet and stop failed deployment/task pairs.
4. Run reasoning-quality and economic-semantic rounds for survivors.
5. Repeat safety-sensitive cases at least three times and compare semantic invariants.
6. Report task-specific qualification, latency, usage, and cost without activating routes.

## Hard boundaries

- Synthetic repository-owned fixtures only; `DataClassification.PUBLIC` is used solely as the
  M2.5 wire classification and does not permit real public website content in this milestone.
- Total actual/reserved cost may not exceed USD 50; each deployment has a sub-budget.
- Credentials and raw request/response bodies are never persisted.
- Live execution is absent from normal CI and must be explicitly invoked.
- No provider tools, search, URL context, browsing, code execution, files, functions, computer use,
